# Process

How work gets done in this repo — the conventions that govern review, release,
and the definition of done. These describe *this package's own* practice;
cross-cutting practice notes that generalize past it live at the wiki's top
level instead.

Each entry's description is the linked page's frontmatter `description`, so the
index and the page can't drift.
